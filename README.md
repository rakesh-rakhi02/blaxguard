
# BlaxGuard 🛡️

BlaxGuard is a scam detection project designed to help protect users from suspicious links, scam messages, and fake loan apps.

## Features
- Suspicious link detection
- Warning badges for potentially dangerous links
- Browser extension support
- Telegram bot integration
- WhatsApp integration (if configured)

## Technology Stack
- HTML, CSS, JavaScript
- Chrome Extension APIs
- Telegram Bot API
- WhatsApp Business Platform (if configured)

## Installation
1. Download or clone this repository.
2. Open Chrome or Edge and navigate to the Extensions page.
3. Enable Developer mode.
4. Select **Load unpacked**.
5. Choose the BlaxGuard extension folder.

## Disclaimer
BlaxGuard provides warnings to help identify potential scams. Detection results may not always be accurate.
